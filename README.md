# منشئ قوالب الاستراتيجيات التعليمية

نسخة مستقلة جاهزة لـ GitHub Pages، باللغة العربية وباتجاه RTL.

## الملفات
- `index.html` — التطبيق كاملًا.
- `moe-logo.png` — شعار وزارة التعليم المرفق.
- `README.md` — تعليمات النشر.

## النشر
1. أنشئي مستودعًا جديدًا على GitHub.
2. ارفعي الملفات الثلاثة إلى جذر المستودع.
3. من Settings → Pages اختاري Deploy from a branch.
4. اختاري `main` و`/ (root)` ثم Save.

لا يحتاج المشروع إلى Node.js أو قاعدة بيانات.

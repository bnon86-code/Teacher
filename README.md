# منشئ قوالب الاستراتيجيات التعليمية

نسخة مستقلة جاهزة لـ GitHub Pages، مصممة لطالبات المرحلة المتوسطة.

## المزايا
- شعار وزارة التعليم مضمّن داخل `index.html` نفسه، ولا يحتاج ملف صورة منفصل.
- نماذج A4 منظمة مع مساحات كتابة فعلية.
- منظمات بصرية تساعد الطالبة على ترتيب أفكارها.
- خمس استراتيجيات: حل المشكلات بالمنظم، التعلم التعاوني، العصف الذهني، الاستقصاء، قراءة الصور.
- طباعة مباشرة أو حفظ PDF من المتصفح.
- لا يحتاج Node.js أو قاعدة بيانات أو مكتبات خارجية.

## النشر على GitHub Pages
1. ارفعي `index.html` إلى المستودع.
2. من Settings → Pages اختاري Deploy from a branch.
3. اختاري `main` و`/ (root)` ثم Save.

# منشئ قوالب الاستراتيجيات التعليمية

صفحة HTML مستقلة تعمل مباشرة على GitHub Pages.

## التشغيل محليًا
افتح `index.html` في المتصفح.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع `index.html`.
3. من Settings → Pages اختر النشر من الفرع `main` والمجلد `/root`.
4. افتح الرابط الذي ينشئه GitHub Pages.

لا يحتاج المشروع إلى Node.js أو قاعدة بيانات أو خادم.
